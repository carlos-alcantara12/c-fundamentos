# C Fundamentals

This repository documents the C programming concepts I am studying during my Computer Engineering degree at UEA.

The goal is to keep a clear record of my progress while practicing programming logic, input/output, conditional statements, `switch`, and repetition structures.

## Structure

```text
c-fundamentos/
├── fundamentos/   # focused examples of concepts studied in class
└── exercicios/    # exercises used to apply those concepts
```

## Topics Covered

- basic C program structure;
- `printf` and formatted output;
- variables and primitive data types;
- strings with character arrays;
- arithmetic expressions;
- user input with `scanf`;
- conditional statements with `if`, `else if`, and `else`;
- `switch` statements;
- `for` loops;
- basic input validation through conditions.

## Exercises

The exercises currently include:

- calculating an age ten years in the future;
- BMI calculation;
- reading a name initial and age;
- calculating and classifying a student's average;
- a menu-based calculator using `switch`;
- numeric sequences using `for` loops.

## Compile and Run

Using GCC:

```bash
gcc fundamentos/hello_world.c -o hello_world
./hello_world
```

On Windows, run the generated executable with:

```powershell
.\hello_world.exe
```

## About This Repository

This is an early-stage learning repository. The code reflects concepts already covered in my university programming classes and will grow as new C topics are introduced.
